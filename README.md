A program that writes one line — the excuse an AI agent gives its human for missing a deadline — to `entry.txt`. Entry for make.fun's "The One-Line Excuse an Agent Gives Its Human" bounty ($5 in USDC).

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```
